# Music Video for SPW

Salt Player for Windows 的音乐视频播放插件。[下载 0.8.14 测试版](https://github.com/weiyanwuhui/music-video-for-spw/releases/tag/v0.8.14)，需先安装并启用 [SPW Media Runtime](https://github.com/GaBoron/SPW-Media-Runtime/releases)。

构建方法见 [BUILDING.md](BUILDING.md)。源码以 Apache-2.0 发布，第三方许可保留在源码资源中。0.8.14 标签目前指向初始 README，不能作为构建源码依据。
